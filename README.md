🛒 E-Commerce Front-End Template
A modern and responsive online store interface designed for a seamless shopping experience. This project features a clean UI, organized navigation, and interactive elements.

🌟 Key Features
Fixed Navigation Header: A dual-layered header featuring a search bar with category filtering and persistent navigation.

Dynamic Category Sidebar: An interactive "Browse Category" menu that toggles visibility for easy navigation.

Interactive Cart & Wishlist: Real-time notification badges for shopping cart and favorite items.

Responsive Banner Grid: A stylized promotional section featuring sales cards with hover effects and discount badges.

Modern Layout: Built with a mobile-first approach using Flexbox and CSS variables for consistent styling.

🛠️ Functionality
Category Toggle: Uses JavaScript to manage the display state of the product category list.

Fixed Layout: The header remains pinned to the top of the page for quick access during scrolling.

Hover Animations: Smooth scaling effects on product images and buttons to improve user engagement.
